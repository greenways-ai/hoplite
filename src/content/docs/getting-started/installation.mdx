## Build from source


1. Clone Hara and Hoplite into sibling directories.

   ```sh
   git clone https://github.com/hara-lang/hara.git hara.lang
   git clone https://github.com/greenways-ai/hoplite.git hoplite
   cd hoplite
   ```

2. Prepare the development dependencies.

   ```sh
   make setup
   ```

3. Run the project checks and build the standalone executable.

   ```sh
   make check
   make macos
   ```


Run `make help` for the available development, packaging, example, and benchmark targets. To install a source build under a custom prefix:

```sh
make install PREFIX=/usr/local
```

## Homebrew package

Hoplite is published to the `greenways-ai` Homebrew tap. Install it with the
fully-qualified formula name:

```sh
brew install greenways-ai/tap/hoplite
hoplite version
```

Naming the tap in the command is what lets the install proceed without extra
setup: Homebrew auto-taps `greenways-ai/homebrew-tap` and treats the explicit
`greenways-ai/tap/hoplite` reference as consent to load the formula. If you
tap first and install by the short name instead, Homebrew 6 refuses to load
the formula until you trust the tap:

```sh
brew tap greenways-ai/tap
brew trust greenways-ai/tap
brew install hoplite
```

The formula builds Hoplite from source (Rust toolchain required) on macOS and
Linux. See [Packaging](/guides/packaging/) for the release flow.
