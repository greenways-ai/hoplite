<span class="doc-badge doc-badge--caution">Pre-release</span> <span class="doc-badge doc-badge--note">Active development</span>

Hoplite is usable from source for development and integration work. The first
pre-release HARP artifacts are published, but the interfaces may still change
before a stable release.

![A network of bronze and verdigris mosaic shields connected as technical nodes](/images/hoplite-shield-network.webp)

## Platform matrix

| Area | Current status |
| --- | --- |
| macOS arm64 | Primary build and standalone packaging target |
| macOS Intel | Primary build and standalone packaging target |
| Linux | Exercised by CI and Docker |
| Embedded Nginx | Statically linked into the standalone executable |
| Hara application bytecode | Generated and validated |
| Nginx bytecode bootstrap ABI | Integration in progress; HAL bootstrap remains active |
| HARP | `gh:greenways-ai:hoplite` and the SQLite store addon have immutable v0.1.0 release artifacts |
| Homebrew | Formula automation prepared; binary distribution pending |
| Authentication | HAL policy and store adapters are exact-version, archive-digest, content-integrity, and contract-version checked before gateway activation |

## Active milestones

<div class="doc-card-grid">
  <article class="doc-card"><h3>Binary distribution</h3><p>Publish verified arm64 and Intel macOS artifacts and the generated Homebrew formula.</p></article>

  <article class="doc-card"><h3>Linux packaging</h3><p>Promote Linux from CI and Docker validation to a supported distribution path.</p></article>

</div>
