---
title: Legacy hoplite.auth
description: Migration note for the removed Hoplite-owned authentication path.
---

:::caution[Removed from current releases]
`hoplite.auth`, its management gateway, and its auth-store adapter are not part
of the supported Hoplite runtime. The retained `legacy-management` Cargo feature
exists only for migration validation and is disabled in release builds.
:::

Do not add `hoplite.auth` imports or package exports to a new application.
Existing callers should move authentication and authorization into ordinary HAL
handlers. A handler can validate its chosen credentials, call narrowly scoped
native cryptographic or storage capabilities, and return an application-owned
principal or rejection response.

See [Authentication](/guides/authentication/) for the current model and
[`hoplite.host`](/reference/hoplite-host/) for the low-level capabilities
available to installed packages. Direct signed-route ingress and the former
Hoplite-owned management gateway have no current replacement API.

The former source remains in the repository for migration comparison only:
[`core/lib/src/hoplite/auth.hal`](https://github.com/greenways-ai/hoplite/blob/main/core/lib/src/hoplite/auth.hal).
