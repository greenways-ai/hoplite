<span class="doc-badge doc-badge--caution">Experimental</span>

`hoplite.socket` is Hoplite's OpenResty-compatible cosocket surface. Network
operations suspend the Hara coroutine while Nginx continues serving other
connections. Application code uses typed namespace functions rather than public
service and operation strings.

The current production stream slice provides numeric IPv4 and IPv6
destinations, explicit Unix-domain targets, fixed, line, and all-data receive
modes, `receiveany`, stateful `receiveuntil` delimiter readers, send-direction
half-close, and a bounded `setoption` surface. DNS, keepalive pools, TLS,
concurrent read/write, and UDP remain tracked by the
[cosocket programme](https://github.com/greenways-ai/hoplite/issues/163);
they are not silently emulated with blocking I/O.

## Basic TCP client

```clojure
(ns example.redis-line
  (:require [hoplite.socket :as socket]))

(defn ^:async request-line [address port request]
  (let [client
        (std.foundation.coroutine/await
         (socket/tcp))
        configured
        (std.foundation.coroutine/await
         (socket/settimeouts client 1000 1000 1000))
        connected
        (std.foundation.coroutine/await
         (socket/connect client address port))]
    (if
     (get connected 1)
     connected
     (let [sent
           (std.foundation.coroutine/await
            (socket/send client request))
           received
           (if (get sent 1)
             [nil (get sent 1) nil]
             (std.foundation.coroutine/await
              (socket/receive client "*l")))]
       (std.foundation.coroutine/await
        (socket/close client))
       received))))
```

The descriptor returned by `tcp` is opaque request authority. Its numeric
handle is validated against the exact request, work, worker, socket kind, and
native generation. Do not persist it, place it in a shared zone, or transfer it
to another request.

## Result convention

The API preserves OpenResty's ordinary error-return style:

| Operation | Success | Network failure |
| --- | --- | --- |
| `connect`, `shutdown`, `close`, timeout setters, `setoption` | `[1 nil]` | `[nil error]` |
| `send` | `[bytes-sent nil]` | `[nil error]` |
| `receive` | `[data nil nil]` | `[nil error partial]` |
| `receiveany` | `[data nil nil]` | `[nil error partial]` |
| `receiveuntil` reader | `[data nil nil]` | `[nil error partial]` |
| `getreusedtimes` | `[count nil]` | `[nil error]` |

Invalid descriptors, malformed arguments, foreign handles, and unsupported
operations reject the host Promise as programming or authority errors. Refused
connections, timeouts, closure, and other network outcomes resolve as ordinary
result vectors so translated OpenResty control flow remains natural.

## `tcp`

```clojure
(std.foundation.coroutine/await
 (socket/tcp))
```

Creates one request-scoped TCP descriptor. Request completion, disconnect,
cancellation, timeout teardown, worker shutdown, or explicit `close` closes the
native connection exactly once.

## `connect`

Numeric IPv4 and IPv6 destinations use the host-and-port form:

```clojure
(std.foundation.coroutine/await
 (socket/connect client "127.0.0.1" 6379))
```

This form accepts numeric addresses and an empty options map. A hostname returns
`"numeric address required"` rather than performing a blocking resolver call.
Nginx-resolver integration, `pool`, `pool_size`, and `backlog` options are
subsequent slices of the same public contract.

Unix-domain stream sockets use the explicit two-argument target form:

```clojure
(std.foundation.coroutine/await
 (socket/connect client "unix:/run/example/service.sock"))
```

Only absolute targets beginning with `unix:/` enter the Unix-domain branch. The
path is parsed by Nginx, bounded by the platform `sockaddr_un` path capacity,
and copied into request-owned native state before the call can suspend. Empty,
relative, embedded-NUL, and overlong targets are programming errors. Missing or
refused sockets resolve through the ordinary `[nil error]` network result.

After connection, Unix-domain sockets use the same nonblocking `send`,
`receive`, `receiveany`, `receiveuntil`, timeout, shutdown, close, cancellation,
disconnect, and worker-exit lifecycle as numeric TCP connections. No blocking
filesystem or socket compatibility path is introduced.

## `send`

```clojure
(std.foundation.coroutine/await
 (socket/send client "PING\r\n"))
```

Accepts strings or bytes up to 1 MiB per call. Partial kernel writes are resumed
from the Nginx write event. A send timeout or connection error closes the
connection because the protocol position is no longer safely reusable.

## `shutdown`

```clojure
(std.foundation.coroutine/await
 (socket/shutdown client "send"))
```

The current slice supports only the `"send"` direction. It sends the stream FIN
after already queued bytes while leaving the receive direction open, allowing a
peer that waits for end-of-request EOF to send its response on the same
connection. Further `send` calls resolve as `[nil "closed"]`; receive operations
and the final exactly-once `close` remain valid. Other direction values are
rejected as programming errors rather than being approximated with a full
close.

## `receive`

```clojure
(socket/receive client 16)    ;; exactly 16 bytes
(socket/receive client "*l")  ;; one line, without LF or a preceding CR
(socket/receive client "*a")  ;; all bytes until the peer closes
```

Every receive is bounded to 1 MiB in this alpha slice. A timeout or premature
close returns the bytes already consumed as the third result value.

## `receiveany`

```clojure
(socket/receiveany client 4096)
```

Returns as soon as at least one byte is available, without waiting to fill the
requested maximum or for the peer to close. The maximum must be from 1 through
1,048,576 bytes. The result uses the same closed three-value receive shape as
`receive`, even though the corresponding OpenResty Lua API exposes two return
values.

## `receiveuntil`

```clojure
(let [reader
      (std.foundation.coroutine/await
       (socket/receiveuntil client "--boundary--"))]
  (std.foundation.coroutine/await (reader)))
```

Awaiting `receiveuntil` creates one request-scoped reader function. Calling
that function without a size returns the bytes before the next delimiter.
The reader may be called repeatedly and preserves bytes after each match.
Delimiters may span any number of Nginx kernel-read boundaries.

Pass `{:inclusive true}` to include the delimiter itself:

```clojure
(socket/receiveuntil client "_END_" {:inclusive true})
```

Passing a positive size turns the reader into a bounded iterator. It
returns chunks until the delimiter is consumed, then returns
`[nil nil nil]` once before resetting for the next delimiter:

```clojure
(std.foundation.coroutine/await (reader 4096))
```

Patterns are bounded to 4096 bytes and individual results to 1 MiB. A
read timeout leaves the connection open and returns consumed bytes as the
partial value. Other connection failures close the connection.

## Timeouts

```clojure
(socket/settimeout client 2000)
(socket/settimeouts client 500 2000 3000)
```

Timeouts are milliseconds from `0` through `3,600,000`. Zero disables the
corresponding timer. `settimeout` assigns one value to connect, send, and read;
`settimeouts` sets them independently.

## `setoption`

```clojure
(socket/setoption client "keepalive" true)
(socket/setoption client "reuseaddr" 1)
(socket/setoption client "tcp-nodelay" true)
(socket/setoption client "sndbuf" 32768)
(socket/setoption client "rcvbuf" 32768)
```

`setoption` is available only after `connect` has established a stream
connection. The current compatibility set is deliberately closed to the five
OpenResty options above. `keepalive`, `reuseaddr`, and `tcp-nodelay` accept a
boolean or `0`/`1`; `sndbuf` and `rcvbuf` accept integers from `0` through the
native `INT_MAX`. Unsupported names, invalid values, and options unsupported by
the connected transport are errors rather than an arbitrary native
`setsockopt` escape hatch.

The option is applied directly to the request-owned native socket. A kernel
`setsockopt` failure resolves as `[nil error]`; success resolves as `[1 nil]`.
Options remain effective until the connection closes. The later keepalive-pool
slice must preserve option-sensitive connection semantics rather than silently
reusing an incompatible pooled connection.

## OpenResty translation

| OpenResty Lua | Hoplite Hara |
| --- | --- |
| `ngx.socket.tcp()` | `(await (socket/tcp))` |
| `sock:connect(host, port)` | `(await (socket/connect sock host port))` |
| `sock:connect("unix:/path")` | `(await (socket/connect sock "unix:/path"))` |
| `sock:send(value)` | `(await (socket/send sock value))` |
| `sock:shutdown("send")` | `(await (socket/shutdown sock "send"))` |
| `sock:receive("*l")` | `(await (socket/receive sock "*l"))` |
| `sock:receiveany(max)` | `(await (socket/receiveany sock max))` |
| `sock:receiveuntil(pattern)` | `(await (socket/receiveuntil sock pattern))` |
| `sock:settimeout(ms)` | `(await (socket/settimeout sock ms))` |
| `sock:settimeouts(c, s, r)` | `(await (socket/settimeouts sock c s r))` |
| `sock:setoption(name, value)` | `(await (socket/setoption sock name value))` |
| `sock:getreusedtimes()` | `(await (socket/getreusedtimes sock))` |
| `sock:close()` | `(await (socket/close sock))` |

`await` above abbreviates `std.foundation.coroutine/await`.

## Current phase and concurrency boundary

This first slice runs from suspended HTTP content handlers. Hoplite currently
serializes native host operations within one request, so it does not yet claim
OpenResty's simultaneous one-reader/one-writer behaviour. The typed Nginx phase
and cancellation work in
[issue #164](https://github.com/greenways-ai/hoplite/issues/164) supplies the
phase-legality registry and concurrent directional operations.

No production path uses a blocking socket compatibility implementation.
