Hoplite is published through Homebrew, standalone macOS and Linux binaries,
and the `ghcr.io/greenways-ai/hoplite` OCI image. The current release is usable
for application and integration work, while interfaces may still change before 1.0.

![A rabbit moving through the junction of three sunlit mosaic garden paths](https://oss.greenways.ai/visual-language/artwork/hoplite/branching-paths-day.webp)

## Platform matrix

| Area | Current status |
| --- | --- |
| macOS arm64 | Supported standalone binary and Homebrew formula |
| macOS Intel | Supported standalone binary and Homebrew formula |
| Linux arm64 | Supported standalone binary, Homebrew formula, and OCI image |
| Linux x86-64 | Supported standalone binary, Homebrew formula, and OCI image |
| Embedded Nginx | Statically linked into the standalone executable |
| Hara application bytecode | Generated and validated |
| Nginx bytecode bootstrap ABI | Integrated; workers transactionally load the generated alpha `app.hbx` bundle |
| Portable host providers | Fixed worker-local registry with bounded HTA request and completion contracts |
| Blob provider | Source artifact 0.1.1 is digest-pinned and independently composed |
| Authentication | Application-owned HAL policy; no default account, session, or management service |

  <article class="doc-card"><h3>Published HTTP benchmarks</h3><p>Report throughput, tail latency, resident memory, machine shape, concurrency, and response size together.</p></article>

  <article class="doc-card"><h3>Deployment templates</h3><p>Turn the published OCI image into direct launch paths for major container services.</p></article>

</div>
