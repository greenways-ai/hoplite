Hoplite is a Hara application server built directly into Nginx. Applications
are immutable resource trees, operations point to Hara Vars, and every Nginx
worker resolves and compiles its handlers during startup.

```text
request → nginx worker → cached Hara handler → native response
```

<div class="doc-card-grid">
  <article class="doc-card"><h3>Application as data</h3><p>Routes and operations are declarative values that can be validated before serving traffic.</p></article>
  <article class="doc-card"><h3>Worker-local runtime</h3><p>Each Nginx worker owns one Hoplite runtime, its values, fibers, promises, and compiled handlers.</p></article>
  <article class="doc-card"><h3>Capability-bound host</h3><p>Hara code calls explicitly installed host services rather than ambient system APIs.</p></article>
  <article class="doc-card"><h3>One operational surface</h3><p>One executable checks, builds, serves, reloads, inspects, installs, and stops applications.</p></article>
</div>
